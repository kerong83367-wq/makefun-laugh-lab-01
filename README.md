A robot vacuum's excuse: "I'm sorry, I ate your sock. In my defense, it was
on the floor, it smelled like adventure, and nobody told me the laundry
basket was a no-eat zone." The program writes it to `/output/entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

Node 22, standard library only, no network. Two runs produce byte-identical output.
